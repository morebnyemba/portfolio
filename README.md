# Portfolio

Personal portfolio site for Moreblessing Nyemba — full-stack engineering, AI/LLM
integrations, and project work. Built with Next.js (App Router) and Tailwind CSS.

Intended to deploy at `morebnyemba.slykertech.net`.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

- `src/app` — routes, layout, global styles
- `src/components` — page sections (Nav, Hero, About, Stack, Projects, Contact, Footer)
- `src/lib/data.ts` — content: contact info, stack, featured projects

## Build

```bash
npm run build
npm run start
```
